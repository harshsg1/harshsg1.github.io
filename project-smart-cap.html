// iot_medical_device

Smart Pill Bottle Cap

ESP32-S3 KiCad C++ IoT

Objective

To engineer a functional IoT medical device subsystem capable of actively monitoring client medication timelines and verifying ambient containment profiles.

Result

An integrated enclosure prototype utilizing an ESP32-S3 microcontroller coupled with precision temperature sensors and a targeted haptic motor driver circuit. Built custom multi-layer circuit footprints within KiCad, verifying low-power trace routing alongside real-time state machine code in C++.

Tools & Technologies
