// low_level_game_engine

Custom C / SDL2 Snake Engine

C SDL2 Linked Lists

Objective

To construct an operational graphical game platform tracking active input states and coordinate arrays without relying on commercial game engines.

Result

A standalone engine structured in pure C utilizing raw SDL2 libraries. Enforced custom memory tracking methodologies by writing dynamic doubly linked lists to handle coordinate segments smoothly while maintaining strict runtime velocity limits.

Tools & Technologies

C SDL2 Doubly Linked Lists Manual Memory Management
