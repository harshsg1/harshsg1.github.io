Raspberry Pi Omni-Wheel Robot

Raspberry Pi Python OpenCV Inverse Kinematics Machine Learning Ultrasonic Sensor

Platform Overview

A Raspberry Pi sits at the core of a four-wheel omnidirectional drive platform, giving the robot full freedom of movement across a plane rather than the forward/turn constraints of a standard chassis. Mounted on top is a robotic arm with a claw end-effector for picking up and relocating objects, alongside an ultrasonic distance sensor for proximity sensing and an onboard camera for vision-based tasks.

Multi-Colour Line Detection

The camera feed is processed to detect and follow lines across multiple colours, letting the robot track a path in real time and adjust the omnidirectional drive to stay on course.

Obstacle Avoidance

The ultrasonic sensor continuously measures distance to nearby obstacles, feeding into the drive logic so the robot can detect obstructions and re-route around them autonomously.

IK Pick-and-Place

Building on the sensing stack, the camera identifies blocks and their shapes, and inverse kinematics translates that position into joint angles for the arm, letting the claw reach down, pick up the identified block, and move it to a new location.

Machine Learning Sorting (Final Build)

The final version of the project layered machine learning on top of the pick-and-place pipeline: an image classifier trained to distinguish dogs from cats determines which of two labelled images a block should be dropped on, with the arm using inverse kinematics to pick up the block and place it on the image matching the ML-determined result.
