Interactive Sensor Demo Wall

Embedded Sensors LED Integration Display Systems Drywall & Finishing

Concept

Rather than presenting sensor work on an open breadboard, this project builds a standalone wall to house and demonstrate it properly — a finished, presentation-ready fixture built to show sensor capabilities the way they'd appear in a real installation.

Sensor & Display Integration

The wall houses two sensors and a central screen wrapped in an LED ring linked directly to the sensor readings, so the display and lighting respond live to what the sensors pick up.

Construction & Finishing

The wall was fully built out with framing and drywall, then finished with baseboards, moulding, and paint — taking it from a bare test rig to a complete, functional demo piece.
